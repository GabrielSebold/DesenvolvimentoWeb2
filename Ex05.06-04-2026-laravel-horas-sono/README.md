# Ex05 - Horas de Sono (Laravel)

Exercicio de horas de sono da aula, feito em Laravel.

## Como rodar
Na pasta raiz `DesenvolvimentoWeb2`, roda:

```bash
php .\Ex05.06-04-2026-laravel-horas-sono\artisan serve --port=8001
```

Depois abre:

```text
http://127.0.0.1:8001
```

## Teste rapido
Dentro da pasta do exercicio:

```bash
php artisan test
```
