# Ex05 - Laravel - Horas de Sono

Projeto da atividade de Desenvolvimento Web 2 com Laravel (MVC).

## Requisitos do exercicio atendidos
- Projeto Laravel.
- Formulario de entrada.
- Uso de template Blade.
- Uso de Model e Controller.
- Funcionalidade de avaliacao da qualidade do sono.

## Campos solicitados
- Idade
- Numero medio de horas dormidas

## Regra implementada
- O resultado informa a faixa ideal de horas conforme idade.
- Classifica o sono como abaixo do ideal, adequado ou acima do ideal.

## Execucao
1. Abra o terminal nesta pasta.
2. Rode:

```bash
composer install
```

3. Rode o servidor:

```bash
php artisan serve
```

4. Acesse no navegador:

```text
http://127.0.0.1:8000
```

## Testes
Rode os testes automatizados com:

```bash
php artisan test
```
