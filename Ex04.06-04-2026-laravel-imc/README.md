# Ex04 - IMC (Laravel)

Exercicio de IMC da aula, feito em Laravel.

## Como rodar
Na pasta raiz `DesenvolvimentoWeb2`, roda:

```bash
php .\Ex04.06-04-2026-laravel-imc\artisan serve --port=8000
```

Depois abre:

```text
http://127.0.0.1:8000
```

## Teste rapido
Dentro da pasta do exercicio:

```bash
php artisan test
```
